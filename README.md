# Divora Homes

Homepage prototype with the live 3D apartment hero (three.js, GLB model).

- `index.html` – latest homepage (v3), a copy of `Divora Homepage v3.dc.html`
- `DivoraHeroLive.dc.html` + `divora-hero-live.js` – live scroll-scrubbed 3D hero
- `uploads/apartment_floor_plan-42f4f1f0.glb` – 3D model, “apartment floor plan” by SrMonteiro, CC BY 4.0

Static site, no build step. To preview locally: `npx serve .`
